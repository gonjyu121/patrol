# AHK 再接続 v11（Falix停止ロビー検知版）

v10を残して新規作成しました。AutoHotkey v2を使用し、既存の `anti_afk_simple_assets` フォルダをそのまま使います。

## v11の追加機能

通常の切断復帰後、Falixの本サーバーが停止していると待機ロビーへ接続されることがあります。v11はMinecraftのクライアントログに出る次の汎用メッセージを検知します。

- `This server is currently offline`
- `Start it by clicking the link below`

検知すると短い警告音を鳴らし、左上表示を「Falix停止ロビーを検知」へ切り替え、視点・左右移動の演出を停止します。チャットに表示されるサーバー固有の起動URLは読み取り結果やAHKログへ保存しません。

## 復旧手順

1. 左上の停止ロビー表示または警告音を確認します。
2. **F9**でFalix管理画面を開きます。
3. 対象サーバーの起動ボタンを手動で押し、起動完了まで待ちます。
4. Minecraftで本サーバーへ手動で再接続します。
5. 本サーバーへ入った後、Minecraftを前面にして **F6** を押し、監視を再開します。

F9が開くのはFalixの一般的な管理画面トップだけです。サーバーの起動ボタン、チャット内の外部起動リンク、CAPTCHAは自動操作しません。サーバーID・接続先・外部起動URLはコードに含めていません。

## 通常時の操作

- **F6**: 監視開始
- **F7**: 監視停止（手動切断前にも使用）
- **F8**: AHK終了
- **F9**: Falix管理画面を開く

画像登録やログフォルダ指定などの初期設定は不要です。ログは `%AppData%\PatrolReconnectV11\reconnect.log` に保存します。

## 引き継いだ機能

v10の切断ログ・切断画面直接検知、選択状態の「サーバーリストへ戻る」ボタン対応、登録サーバー画像の厳しい照合条件、誤操作防止、監視状態表示を維持しています。

AHK単体のv11更新のためPaperプラグインのバージョンやJARは変更していません。
