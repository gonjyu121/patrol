# AHK 再接続 v8（切断画面の直接検知版）

v7を残して新規作成しました。AutoHotkey v2を使用し、認識画像はバージョン共通の `anti_afk_simple_assets` フォルダをそのまま使います。

## v8の変更点

v7は監視開始後のログにConnection reset等が出た場合だけ画像認識へ進んでいました。v8はログに該当行が出ない場合や、切断画面が先に表示された場合でも、F6で監視中かつ対象Minecraftが最前面なら「サーバーリストへ戻る」ボタンを毎秒直接確認します。

ボタンを検知するとログへ「切断画面を直接検知」と記録し、10秒後に同じ画面を再確認してからクリックします。画面が変わっていれば操作せず停止します。

## 使い方

1. 旧AHKをF8またはタスクトレイから終了します。
2. `anti_afk_simple_v8.ahk` と既存の `anti_afk_simple_assets` を同じ場所に置き、v8を実行します。
3. Minecraftを前面にして **F6** を押します。
4. Minecraftが最前面でフォーカスされている間、左上に点滅する監視状態と、小さな「自動演出中」が表示されます。
5. 通常監視中は15秒ごとに視点とA・Dの短い往復演出を行います。
6. **F7** で監視停止、**F8** で終了します。手動切断・メンテナンス前にもF7を押してください。

画像登録やログフォルダ指定などの初期設定は不要です。開始操作のF6だけ必要です。

## 安全条件

- 画像の直接検知は、F6で登録した対象Minecraftが現在最前面の場合だけ行います。
- 再接続操作の直前にも対象ウィンドウと画像を再確認します。
- 1回の監視につき接続操作は最大3回です。
- 重複ログイン・キック、画像不一致、対象ウィンドウ終了、処理時に別アプリが前面の場合は停止します。
- 手動で切断画面を開く場合も画像が一致するため、事前にF7で停止してください。
- 演出の左右移動は地形により完全に元へ戻らない場合があります。落下の危険がない場所で使用してください。

画像認識は撮影時と同じMinecraft GUIスケール・言語・Windows表示倍率が前提です。

ログは `%AppData%\PatrolReconnectV8\reconnect.log` に保存します。認証情報やゲームログ全体は保存しません。

## 検証と配布

`--self-test` はログ検知、除外条件、切断画面トリガー、起動引数解析と、共通PNGからのBMP生成を検証します。テスト中はGUI・入力・サーバー操作を行いません。実際のMinecraft画面での画像照合と再接続は配信用PCで初回確認してください。

AHK単体のv8更新のためPaperプラグインのバージョンやJARは変更していません。
