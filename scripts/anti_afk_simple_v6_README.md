# AHK 再接続 v6（配信用PC・同梱画像版）

v4を残して新規作成。画像登録（F9/F10）とログフォルダ選択（F5）は不要です。AutoHotkey v2を使用してください。

## 使い方

1. 旧AHKをF8またはタスクトレイから終了します。
2. `anti_afk_simple_v6.ahk` を実行し、案内を閉じます。同じ場所のバージョン共通 `anti_afk_simple_assets` フォルダも必要です。
3. Minecraftを前面にして **F6**。実行中のMinecraftの起動引数 `--gameDir` を確認し、指定がなければ標準の `%AppData%\\.minecraft` を使ってログの場所を自動判別し、監視を開始します。
4. **F7** ですべての監視・予約操作を停止。手動切断・メンテナンスの前にも押してください。**F8** で終了。

初期設定は不要ですが、開始操作のF6は必要です。自動起動やWindowsの設定変更はしません。ZIPを使う場合は全体を展開してから実行してください。

## 動作

- 頂いた原寸スクリーンショット2枚を同梱。起動時に「サーバーリストへ戻る」の文字と `otougame.falixsrv.me` の名前部分を自動で取り出します。変動する人数・pingは使いません。
- 新しいConnection reset等のログ、または `debug/disconnect-*-client.txt` の新規・更新レポートで検知。監視開始時点の古い記録は無視します。
- 10秒後に戻るボタンの画像を確認してクリック、4秒後に対象サーバー名を確認してダブルクリック。画像の寸法に合わせた中央をクリックします。
- 対象ウィンドウが前面でない・画像不一致・ログ取得失敗なら通知して停止。別のアプリや不明な画面にTab/Enterを送りません。
- F6で開始した1回の監視につき最大3回の接続操作。1つの障害で無制限にリトライしません。接続操作後に再び通信エラーを検知した場合も停止します。
- 接続30秒後も既知のメニュー画像が見えれば停止。それ以外では追加操作をせず監視へ戻ります。「画像が消えた＝接続成功」とは断定せず、成功通知は出しません。
- 重複ログイン・キック等を検知したら停止。理由がConnection resetしかない場合は、手動停止との完全な区別はできないためF7を使用してください。

定期的な移動・キー送信・AFK維持・Falixへの起動操作・広告や無料枠制限の回避は行いません。

## 注意

撮影時と同じGUIスケール・言語が前提です。Windowsの表示倍率やGUIスケールが変わり文字のピクセルサイズが変化した場合、画像が一致せず停止します。初回は必ず付き添いで確認してください。最小化・背面では操作しません。

起動引数に `--gameDir` がなくても、標準の `%AppData%\\.minecraft\\logs\\latest.log` が存在すれば監視できます。どちらにもログがない場合やプロセス情報を読めない場合は理由を通知して停止し、別の古いログを推測して監視しません。

Windows通知と `%AppData%\PatrolReconnectV6\reconnect.log` に動作理由が残ります。Minecraftの起動引数全体・認証トークン・ゲームログ全体を保存しません。認識用BMPも同フォルダに自動生成され、旧v4の設定には触れません。

## 検証と配布

AutoHotkey v2の `--self-test` で検知・除外・起動引数解析14件と、同梱PNGからのBMP生成2件を検証。テストでは画面入力やサーバー操作を行いません。配信用PCでの実際の画像照合と再接続は未検証です。

AHK単体のv6更新のためPaperプラグインのバージョンやJARは変更していません。旧v4を残して配布ZIPを生成します。
