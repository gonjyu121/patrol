# AHK 再接続 v10（選択状態ボタン対応版）

v9を残して新規作成しました。AutoHotkey v2を使用し、既存の `anti_afk_simple_assets` フォルダをそのまま使います。

## v10の修正

2026年9月8日の `Server closed` 画面では、監視は有効でしたが「サーバーリストへ戻る」ボタンが選択状態の明るさになっていました。既存テンプレートとの比較では8,832ピクセル中73ピクセルの色差が従来許容値15を超え、最大色差は55でした。

v10は戻るボタンだけ画像認識の許容値を60へ変更します。実測した差55に小さな余裕を加えた値です。誤った登録サーバーをクリックしないよう、サーバー名画像の許容値は従来の15から変更しません。

## 使い方

1. v9以前をF8またはタスクトレイから終了します。
2. `anti_afk_simple_v10.ahk` と既存の `anti_afk_simple_assets` を同じ場所に置き、v10を実行します。
3. Minecraftを前面にして **F6** を押します。
4. 左上の点滅表示と、小さな「自動演出中」が見えることを確認します。
5. **F7** で監視停止、**F8** で終了します。手動切断前にもF7を押してください。

画像登録やログフォルダ指定などの初期設定は不要です。

## 再接続

v9と同じく、Connection reset、Server closed等のログ、または前面Minecraftの「サーバーリストへ戻る」ボタンを直接検知します。検知後10秒待って戻るボタンを再確認・クリックし、4秒後に登録サーバー名を従来の厳しい条件で確認してダブルクリックします。

F6ごとの接続操作は最大3回です。画像不一致、別アプリが前面、対象終了、重複ログイン・キック等では停止します。停止中のFalixサーバー自体を起動する機能はありません。

ログは `%AppData%\PatrolReconnectV10\reconnect.log` に保存します。

## 検証

`--self-test` は直接画面トリガー、戻るボタンの許容値が実測差55以上であること、サーバー名の許容値が15のままであること、ログ条件、起動引数解析、BMP生成を検証します。テスト中はGUI・入力・サーバー操作を行いません。

AHK単体のv10更新のためPaperプラグインのバージョンやJARは変更していません。
