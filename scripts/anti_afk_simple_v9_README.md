# AHK 再接続 v9（切断画面の直接検知・実装修正版）

v8を残して新規作成しました。AutoHotkey v2を使用し、認識画像はバージョン共通の `anti_afk_simple_assets` フォルダをそのまま使います。

## v9の修正

v8はREADMEと自己テスト表示だけが直接検知対応になり、実際の監視処理がログ検知のまま残っていました。v9では実処理を修正し、F6で監視中かつ対象Minecraftが最前面なら、「サーバーリストへ戻る」ボタンを毎秒直接確認します。

今回提供された `Server closed` 画面と既存テンプレートを比較し、使用範囲276×32ピクセルが完全一致することも確認済みです。また、ログ側の検知語句にも `Server closed` を追加しました。

## 使い方

1. 旧AHKをF8またはタスクトレイから終了します。
2. `anti_afk_simple_v9.ahk` と既存の `anti_afk_simple_assets` を同じ場所に置き、v9を実行します。
3. Minecraftを前面にして **F6** を押します。
4. 左上の点滅する監視状態と、小さな「自動演出中」が表示されることを確認します。
5. **F7** で監視停止、**F8** で終了します。手動切断前にもF7を押してください。

画像登録やログフォルダ指定などの初期設定は不要です。

## 再接続

- ログでConnection reset、Server closed等を検知した場合に開始します。
- ログに該当行がなくても、前面の対象Minecraftで既知の切断ボタンを見つけた場合に開始します。
- 検知後10秒待ち、同じ切断ボタンを再確認してからクリックします。
- 4秒後、登録サーバー画像を確認してダブルクリックします。
- F6ごとの接続操作上限は3回です。
- 画像不一致、別アプリが前面、対象終了、重複ログイン・キック等では停止します。

手動で切断画面を開く場合も直接検知されるため、先にF7で停止してください。通常監視中の15秒ごとの小さな視点・A/D往復と「自動演出中」表示はv8から継続します。

ログは `%AppData%\PatrolReconnectV9\reconnect.log` に保存します。

## 検証

`--self-test` は `Server closed`、ログ条件、除外条件、直接画面トリガー、起動引数解析、共通PNGからのBMP生成を実際に検証します。テスト中はGUI・入力・サーバー操作を行いません。

AHK単体のv9更新のためPaperプラグインのバージョンやJARは変更していません。
