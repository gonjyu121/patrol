# AHK 再接続 v7（監視表示版）

v6を残して新規作成しました。AutoHotkey v2を使用し、認識画像はバージョン共通の `anti_afk_simple_assets` フォルダをそのまま使います。

## 使い方

1. 旧AHKをF8またはタスクトレイから終了します。
2. `anti_afk_simple_v7.ahk` と `anti_afk_simple_assets` を同じ場所に置き、v7を実行します。
3. Minecraftを前面にして **F6** を押します。
4. Minecraftが最前面でフォーカスされている間、画面左上に「●/○ 再接続監視中 0/3」が表示され、0.5秒ごとに丸印が切り替わります。
5. 通常監視中は15秒ごとに視点がごく短く右へ動いて元へ戻り、A・Dによる短い左右移動も往復します。ラベルだけでなく、対象MinecraftへAHKの操作が届く状態かを目視確認し、配信画面に小さな自動演出を加える動作です。
6. **F7** で監視停止、**F8** で終了します。手動切断・メンテナンス前にもF7を押してください。

画像登録やログフォルダ指定などの初期設定は不要です。開始操作のF6だけ必要です。Minecraftからフォーカスを外すと表示は隠れ、戻すと監視が有効な場合だけ再表示されます。

## 表示の意味

- **再接続監視中**: 新しい通信エラーを監視しています。
- **再接続準備中**: 通信エラーを検知し、既知のボタン画像を確認する待機中です。
- **再接続確認中**: サーバーへの接続操作後、追加エラーやメニュー残留を確認中です。
- **0/3～3/3**: 今回F6を押してから実行した接続操作の回数です。
- **●/○の点滅**: AHKの表示更新タイマーが動いていることを示します。
- **15秒ごとの小さな視点・左右移動**: AHKから、現在フォーカスされている対象Minecraftへ操作が届くことを示します。再接続処理中や別アプリが前面のときは実行しません。表示下段の小さな「自動演出中」で自動操作であることを示します。

表示はクリックを透過し、Minecraftの操作を奪いません。演出では相対マウス移動と既定キー設定のA・Dだけを送り、クリック・前後移動・ジャンプは行いません。往復量は小さくしていますが、感度、キー割り当て、地形や当たり判定によっては元の位置・向きへ完全には戻らないことがあります。落下の危険がない場所で使用してください。

## 再接続機能

v6と同じく、`latest.log` と切断レポートからConnection reset等を検知し、Minecraftが前面で既知の画面画像と一致した場合だけ、戻るボタンと登録サーバーをクリックします。試行上限はF6ごとに3回です。重複ログイン・キック、画像不一致、対象ウィンドウの終了、処理時に別アプリが前面の場合は停止します。

ゲームフォルダは対象Minecraftの `--gameDir`、または標準の `%AppData%\\.minecraft` から自動判別します。画像認識は撮影時と同じMinecraft GUIスケール・言語・Windows表示倍率が前提です。

ログは `%AppData%\PatrolReconnectV7\reconnect.log` に保存します。認証情報やゲームログ全体は保存しません。

## 検証と配布

`--self-test` は検知・除外・起動引数解析14件と、共通PNGからのBMP生成2件を検証し、GUI・入力・サーバー操作を行いません。実際のMinecraft上でのオーバーレイ表示と再接続は配信用PCで初回確認してください。

AHK単体のv7更新のためPaperプラグインのバージョンやJARは変更していません。
